# SysMonitor

Фоновый монитор нажатий клавиш для Windows с отправкой лога в Telegram по запросу.

Программа работает в фоне без окна и иконки в трее, пишет нажатия в локальный файл
и по команде `/log` в Telegram отправляет этот файл в чат.

## Возможности

- Глобальный перехват нажатий через `WH_KEYBOARD_LL`.
- Тихая работа: без окна, без иконки в трее, без уведомлений.
- Запись в `keystrokes.txt` рядом с `.exe`.
- Опрос Telegram Bot API: команды `/log` и `/start`.
- Отправка файла лога как документа в Telegram.
- Автозагрузка через реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Требования

- Windows 7 / 8 / 10 / 11.
- .NET Framework 4.0 или выше (входит в состав Windows).
- Telegram-бот и его токен.
- Свой `chat_id` — программа определяет его автоматически при первом сообщении боту.
